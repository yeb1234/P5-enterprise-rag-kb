## 关键裁决（改动时别破）
1. **参数默认值**（写入 03-phase2-spec）：分块 800/80、confidence 0.75、视觉预算 0.10/min_slots 1、
   难度权重 `no_text_layer .30 / ocr_needed .25 / 1−conf .20 / cells .10 / pages .10 / 1−budget .05`、
   PAGE_REF 20 / CELLS_REF 100、θ 0.60/0.40、k=2、固定 `as_of=2026-11-15T00:00:00Z`、8 MiB、端口 8767。
   全部是演示起始值、非压测结论。
2. **路由决策与真实调用解耦**：Pro 档真实触发，但离线演示不发起外部 LLM 调用；
   `model/model_snapshot_at/prompt/prompt_version/params` 一律空占位、`placeholder=true`，不编造值。
3. **保留 k=2 滞回不降**：实跑发现每次新建 `TierState` 会让单次复杂档恒 standard(1/2)、Pro 永不触发。
   改为 `api.py` 按 `(source_sha, params_hash)` 的进程内 LRU（≤32）缓存状态，同档连跑两次才升 pro，不串用户、重启清零。
4. **`snapshot_version` 只由配置性字段派生**（排除 `reason` / `hysteresis`），`route_id` 用全字段：
   否则瞬时滞回计数会改版本→改 run_id→改 manifest 摘要，V5 不成立。
5. **V5 判定口径 = 入库内容规范化投影 `canonical()`**，路径感知剔除 `manifest` 整块、
   `llm_route` 的 `route_id/hysteresis/reason`、任意层级耗时字段；**保留** `trace[].reason` 与 `source.sha256`，
   否则会掩盖真实差异（假阳性）。A8 回放仍用完整 manifest。
6. **观测字段与可复现字段分离**：`latency_ms` 三处同参双跑会变（44→0），`created_at` 取 as_of，挂钟只进 `runtime`。
7. **复杂档视觉结果一律标「离线回放，非实时在线识别」**；`ocr_api` 未接通取 HTTP 200 + errors[]/warnings[] 留痕 + 真实降级结果。
8. **样本命名以现状为准**：`simple.pdf` / `complex.png` / `*.report.json` / `*.canonical.json`，
   架构文档里的规划名 `text_layer.pdf` 等不采用；`server.py` 必须在根 `/` 挂载**之前**挂 `/showcase/samples`。
