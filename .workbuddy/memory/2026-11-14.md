# 19:12 实测纠正：DeepSeek V4.1 Flash 确实是多模态，且低思考档确实生效

用户指出「deepseek-v4.1-flash-1017 理论上应该是多模态模型，你自己尝试测下」。实测结果**推翻了我此前两处判断**，这是今天最重要的一次纠错。

## 三个实测
1. **元数据**：`/models` 每个模型对象带 `input_modalities`。10 个模型里 6 个支持 image（Agents-A1 / Sage-A1.5 / deepseek-v4.1-flash-1017 / intern-s2 / kimi-k3.1-pro / qwen3.8-27b），4 个纯文本。目标模型 image 项写明 `sources.values=["url","base64"]`。我此前只取 `id` 看模型名，属误判。
2. **双图对照传图**：OpenAI 兼容 `image_url` + base64 data URI。图 A（浅蓝/73492/CODE-A）→ 精确回答，1406ms/357 tokens；图 B（浅黄/18620/CODE-B）→ 精确回答，2463ms/433 tokens；两次回答不同，排除「靠猜或复述提示词」。完整链路 `ParseRouter.parse_document()` 复跑：`reason=vision_applied`、`degraded=None`、1403ms。
3. **推理开关四组对照**（同题 `temperature=0`）：基线 979ms/`reasoning_tokens=55`；`thinking={"type":"disabled"}` 467ms/0（**生效**）；`reasoning=false` 3413ms/55；`reasoning=true` 945ms/55。元数据把 `reasoning` 列为 boolean 但**实测无效**——「元数据声明」≠「实际生效」。
